# HIIT・有酸素運動・筋力トレーニングの基礎

HIIT、有酸素運動、筋力トレーニングは、完全に分離した三つの運動種目ではない。

- 有酸素運動と筋力トレーニングは、主に何を鍛えるかで分けた分類である。
- HIITは、高強度の運動と回復を交互に行うトレーニング方法である。
- ランニング、自転車、坂道歩きなどの有酸素運動をHIIT形式で行うこともできる。
- スクワットなどを組み合わせたHIITは、心肺機能と筋持久力の両方に刺激を与える場合がある。

したがって、目的に応じて一つだけを選ぶのではなく、異なる役割を組み合わせることが基本になる。

## 全体像

| 分類 | 主な目的 | 基本的な方法 | 代表例 |
| --- | --- | --- | --- |
| 有酸素運動 | 心肺機能と長時間動き続ける能力を高める | 中程度または高い強度で、全身の大きな筋肉を継続的に動かす | 速歩、ランニング、自転車、水泳 |
| 筋力トレーニング | 筋力、筋量、身体を支える能力を高める | 筋肉に抵抗をかけ、反復と休憩をセット単位で行う | スクワット、腕立て伏せ、ウエイト、ゴムバンド |
| HIIT | 短時間で心肺機能や高強度への耐性を高める | 高強度区間と低強度区間または休息を反復する | ランニング、自転車、坂道歩き、全身運動のサーキット |

「心拍数が上がる運動はすべてHIIT」「息が切れる筋トレはすべて有酸素運動」というわけではない。実際の効果には重なりがあるが、運動の構成と主な負荷によって中心となる目的が変わる。

## 有酸素運動とは

有酸素運動は、脚などの大きな筋肉をリズミカルに、一定時間継続して動かす運動である。運動中は呼吸と心拍数が上がり、継続することで心臓、肺、血管を含む心肺系の能力が向上する。

### 主に鍛えられる能力

- 長時間動き続ける持久力
- 同じ速度を以前より少ない負担で維持する能力
- 心臓と肺から活動中の筋肉へ酸素を運ぶ能力
- 長時間運動するときのペース配分やエネルギー利用

### 代表的なやり方

- 速歩や傾斜ウォーキングを20～60分続ける
- 会話できる程度の余裕を保ってランニングする
- 自転車、エアロバイク、水泳を一定ペースで行う

中強度では「会話はできるが歌うのは難しい」、高強度では「数語話すたびに息継ぎが必要になる」程度が、器具を使わず判断できる目安になる。

## 筋力トレーニングとは

筋力トレーニングは、重り、自重、ゴムバンドなどの抵抗に対して筋肉を働かせる運動である。継続時間よりも、どの筋肉へどれだけの抵抗をかけ、何回、何セット行ったかが重要になる。

### 主に鍛えられる能力

- 大きな力を出す筋力
- 筋肉の量
- 関節や姿勢を安定させる能力
- 立つ、持つ、階段を上るなどの身体機能

### 代表的なやり方

| 動作 | 代表例 | 主に使う部位 |
| --- | --- | --- |
| 膝と股関節を曲げて立つ | スクワット、ステップアップ | 太もも、臀部 |
| 股関節を中心に曲げ伸ばす | ヒップヒンジ、デッドリフト | 臀部、もも裏、背面 |
| 押す | 腕立て伏せ、チェストプレス | 胸、肩、腕 |
| 引く | ローイング、ゴムバンドロー | 背中、腕 |
| 身体を安定させる | プランク、片脚立ち | 体幹、股関節周辺 |

初心者は、各種目を8～12回、1セットから始められる。余裕が出てきたら2～3セットへ増やす。CDCの一般的な健康指針では、脚、臀部、背中、腹部、胸、肩、腕などの主要な筋群を、週2日以上鍛えることが推奨されている。

有酸素運動でも脚は使うが、筋力や筋量を主目的とする場合は、抵抗を徐々に増やせる筋力トレーニングの方が目的に合う。

## HIITとは

HIITは `High-Intensity Interval Training` の略で、高強度の運動区間と、低強度の運動または休息による回復区間を繰り返す方法である。

HIITを成立させる要素は、特定の種目ではなく次の組み合わせである。

1. 高い強度で動く区間
2. 次の高強度区間に備える回復区間
3. この組み合わせの反復

ACSMは、高強度区間の一般的な目安を推定最大心拍数の80～95％、主観的には「きつい～かなりきつい」としている。ただし、年齢から計算した最大心拍数は概算であり、短い運動では心拍計の表示が実際の負荷に遅れて追いつくこともある。心拍数だけでなく、呼吸、主観的なきつさ、フォームを合わせて判断する。

### 主に鍛えられる能力

- 心肺能力
- 高い運動強度へ対応する能力
- 強い運動後に回復し、再び動く能力
- 短時間で心肺系へ強い刺激を与える能力

HIITは心肺能力を時間効率よく高められる。一方で、疲労が大きく、長時間動き続ける経験や筋力向上をすべて代替するものではない。

## HIITの代表的なやり方

### ランニングまたはウォーキング

1. 5分間、歩くかゆっくり走って身体を温める。
2. 30秒間速く動き、60～90秒間ゆっくり動く。
3. 2の組み合わせを4～6回繰り返す。
4. 5分間ゆっくり動いて終了する。

速い区間は全力疾走ではなく、主観的なきつさを10段階で8程度にする。関節への衝撃を抑えたい場合は、速く走る代わりに傾斜を付けて速歩する方法もある。

### エアロバイク

1. 軽い負荷で5分間こぐ。
2. 30秒間、重めの負荷または速い回転でこぐ。
3. 60～90秒間、軽い負荷で回復する。
4. 2と3を4～6回繰り返す。
5. 軽い負荷で5分間こいで終了する。

着地衝撃が少なく、速度や抵抗を調整しやすいため、運動に慣れていない場合にも強度を管理しやすい。

### 全身運動のサーキット

次のような動作を20～30秒ずつ行い、必要に応じて休息を挟んで反復する。

- ステップアップ
- シャドーボクシング
- マウンテンクライマー
- スクワット

サーキット形式では、一つの筋肉だけが先に疲れると、心肺機能へ十分な刺激を与える前に継続できなくなる。動作部位を分散し、疲れても安全なフォームを保てる種目を選ぶ。

ジャンプやバーピーは必須ではない。着地や複雑な動作によってフォームが崩れる場合は、速歩、自転車、ステップアップなどの単純な種目を使う。

## 三つの目的の違い

| 目的 | 優先する運動 | HIITの位置づけ |
| --- | --- | --- |
| 健康維持 | 継続しやすい有酸素運動＋筋力トレーニング | 必須ではない |
| 心肺能力を短時間で高める | HIIT＋回復しやすい有酸素運動 | 中心的な手段になる |
| 長時間歩く・走る | 長めの有酸素運動 | 最大能力を高める補助 |
| 筋力・筋量を増やす | 筋力トレーニング | 心肺機能を補う運動 |
| 登山へ備える | 坂道歩き、階段、長めの歩行＋脚と体幹の筋力トレーニング | 急な登りへ対応する補助 |
| 体脂肪を減らす | 継続できる運動＋食事全体の調整 | 短時間で消費量を増やせるが、特別な近道ではない |

HIITは1分当たりの運動強度を高くしやすいが、体脂肪減少について継続的な有酸素運動より明確に優れるとは限らない。運動方法の名前よりも、長期的に継続できる運動量と食事の影響が大きい。

## 組み合わせ方

健康維持を目的とする成人について、WHOとCDCは週150～300分の中強度有酸素運動、または週75～150分の高強度有酸素運動と、主要な筋群を鍛える筋力トレーニングを週2日以上行うことを推奨している。

これは最低限の予定表を一つに固定するものではない。HIITは高強度有酸素運動の一部として組み込み、疲労や体力に応じて量を調整する。

### 基本的な週間例

| 日 | 内容 |
| --- | --- |
| 1日目 | 余裕のあるウォーキング、ランニングまたは自転車 |
| 2日目 | 全身の筋力トレーニング |
| 3日目 | 休養または軽い運動 |
| 4日目 | HIIT |
| 5日目 | 休養 |
| 6日目 | 長めの有酸素運動＋短い筋力トレーニング |
| 7日目 | 休養または軽い運動 |

HIITは連日行わず、週1回程度から始める。強い疲労や痛みが翌日まで残る場合は、回数、速度、傾斜、抵抗またはセット数を減らす。

## よくある誤解

### 心拍数が高ければHIITになる

HIITには、高強度区間だけでなく、回復区間と反復が必要である。心拍数が高い状態で動き続けるだけなら、高強度の継続運動に近い。

### HIITだけで筋力も持久力もすべて鍛えられる

HIITでも筋肉へ刺激は入るが、筋力を高めるための段階的な抵抗や、長時間動き続ける練習が不足しやすい。筋力トレーニングと継続的な有酸素運動には、それぞれ別の役割がある。

### HIITは毎回全力で行う

全力でなければHIITにならないわけではない。次の区間でもフォームと強度を再現できる範囲に抑える。全力疾走を短い休息で反復する方法は、一般的なHIITより負荷の高いスプリントインターバルトレーニングとして区別される場合がある。

### 汗の量で効果を判断できる

発汗量は気温、湿度、服装、体質にも左右される。運動の強度や効果は、心拍数、呼吸、主観的なきつさ、時間、回数などを組み合わせて判断する。

## 安全に続けるための注意

- 運動前後に5分程度のウォームアップとクールダウンを行う。
- 運動に慣れていない場合は、中強度の有酸素運動から始めて徐々に強度を上げる。
- HIIT中にフォームを維持できなくなったら、速度や抵抗を下げるか終了する。
- 胸の痛み、失神しそうな感覚、異常な息苦しさ、強い動悸が出た場合は中止する。
- 関節や腱の痛みが続く場合は、負荷を下げて回復を優先する。
- 心臓、呼吸器、関節などの持病がある場合や、運動習慣がない状態から高強度運動を始める場合は、事前に医療従事者へ相談する。

最も激しい運動を選ぶことより、目的に合った運動を回復可能な範囲で継続することが重要である。
